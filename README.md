# ZarrArray [<img src="https://bioconductor.org/images/logo/jpg/bioconductor_logo_rgb.jpg" width="200" align="right"/>](https://bioconductor.org/)

**ZarrArray** is an R/Bioconductor package that allows manipulation of Zarr
datasets as DelayedArray objects.

See <https://bioconductor.org/packages/ZarrArray> for more information,
including for how to install the release version of the package (please refrain
from installing directly from GitHub).
